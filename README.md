# side-quests

Small, mostly silly projects about AI coding agents. Each folder stands on
its own: Python 3.9+, stdlib only, nothing leaves your machine.

| Project | What it does |
|---|---|
| [terminally-cooked/](./terminally-cooked/) | Roasts one of your own agent sessions into a comedy results card. Claude Code, Codex, Grok, Gemini CLI. |
| [desk-bench/](./desk-bench/) | When a new model drops, can it clean your desktop? A fake messy desktop, a scorer, a leaderboard. |

Elsewhere: [comics-pipeline](https://github.com/asheppard47/comics-pipeline),
an agent pipeline for single-panel comics.

This repo used to be `terminally-cooked`. Old links and clones redirect here.
